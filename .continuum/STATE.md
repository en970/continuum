# Done

- Watcher (`continuum.py`): detection, reset-time parsing, one send at reset
  plus a single backup attempt, sleep hold, health reporting.
- Two pane backends: tmux (any OS, no permissions) and macOS Terminal.app
  (AppleScript). Auto-detected.
- Claude Code hooks are now the primary signal:
  `StopFailure(rate_limit)` reports the limit exactly; the reset time is read
  from the transcript's structured record (`error: "rate_limit"`,
  `apiErrorStatus: 429`); `SessionStart(startup|resume|clear|compact)` prints
  `.continuum/STATE.md` into a fresh context; `PreCompact` marks a checkpoint
  as due. Screen scraping remains as a fallback.
- SwiftUI picker app at `/Applications/Continuum.app`, icon generated by
  `app/makeicon.swift`. Ticks are stored per project path in `enabled.json`.
- `install.sh` / `--uninstall`, English README with screenshot, MIT licence.
- Skill at `skill/SKILL.md`, linked into `~/.claude/skills/continuum`.

# Worth knowing

- **Screen scraping was the original design and it failed silently.** Patterns
  were written for `usage limit reached`; Claude Code actually says
  `You've hit your session limit · resets 1:50am`. A real limit passed with the
  watcher doing nothing. Hooks exist precisely so this cannot recur.
- **Do not run the watcher under launchd on macOS.** A launchd process needs
  its own Automation permission for Terminal.app; that dialog cannot be
  approved unattended, so `osascript` just times out. Started from a terminal,
  the permission is inherited.
- **The watcher must not be tied to a window.** An early version lived inside a
  Terminal window and was killed by SIGHUP when that window closed — it was
  dead for 9.5 hours unnoticed. It now uses `start_new_session=True`, plus a
  shell hook (`continuum ensure`) that revives it.
- **AppleScript: `contents of <variable>` does not work.** Assigning a tab to a
  variable makes `contents of` resolve to the dereference operator. Address the
  tab directly. Raw control characters in a script literal also break silently;
  use `ASCII character 30`.
- **A reset time in the past does not mean tomorrow.** Limit windows are short,
  so `resets 1:50am` seen at 01:55 means it just reset — resume now. Only roll
  to the next day past 12 hours.
- Trailing blank lines must be trimmed before taking the last N lines of a
  pane, or the limit line falls outside the window.
